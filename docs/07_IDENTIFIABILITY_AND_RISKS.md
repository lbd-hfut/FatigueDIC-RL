# 07 — 可识别性与未解决风险

本文件是项目建模判断和待验证问题，不宣称这些风险已通过 Phase 0 排除。

## 从位移识别 damage 的限制

在给定载荷、几何和材料参数下，前向映射 \(D\mapsto P\,u(D)\) 未必单射。
在线性刚度比例模型中，如果所有边界仅给定位移、没有体力/牵引且刚度被全域统一缩放，
平衡位移可保持相同，而反力随缩放变化。这一推导说明单独位移可能看不到均匀刚度退化。
需研究 force/reaction 信息、多个载荷工况、材料先验和空间/时间正则化。

节点/单元/积分点 damage 自由度常大于有效独立观测信息量。
DIC 质量、遮挡、噪声、坐标偏差、subset 平滑和有限空间分辨率会进一步限制反演。
位移与派生应变的噪声/分辨率权衡已见
[NIST DIC Challenge 2.0](https://www.nist.gov/publications/dic-challenge-20-developing-images-and-guidelines-evaluating-accuracy-and-resolution-2d)；
在本项目里引起何种可识别性退化仍需定量验证。

优先计算有限差分/可微 sensitivity Jacobian 的奇异值、参数相关性，
比较多个加载工况，并报告无法识别的方向。
不可把神经网络单一输出误认为唯一物理解。

## 科学风险

| 风险 | 当前状态 | 后续证据 |
|---|---|---|
| E、边界、几何误差被 damage 吸收 | 未校准 | 参数联合估计与独立标定 |
| 裂纹、塑性、离面运动被标量损伤误解释 | 当前模型不足 | 模型比较与独立观测 |
| hazard 忽略应力比、频率、载荷次序 | 常 hazard 仅示例 | 实验/文献模型和历史测试 |
| 单调 damage 不代表热力学一致 | 只验证代数约束 | 自由能、耗散与耦合能量收支 |
| Dmax 与失效定义不一致 | smoke 用 0.95，无寿命结论 | 阈值定义和失效验证 |
| 估计修正与真实不可逆混淆 | 已区分接口/文档 | 轨迹同化可容许集合 |
| 多步模型误差被 RL 利用 | 没有 RL 运行 | 模型误差分析与保守评价 |
| correction 不能激活零 hazard | 乘法结构的限制 | 与有物理依据的替代结构比较 |

## 工程风险

mesh 检查不含全域重叠/T junction 等完整质量诊断。
quadrature 只有引用契约，没有 element ownership、积分权重与规则数据结构。
tri3 locator 为 O(EQ)，没有空间索引、多线程或磁盘持久化缓存。
quad4/mixed interpolation、高阶单元、3D、多坐标系自动变换均未实现。
MechanicsState 只支持当前二维力学形状及点 belief；tensor convention 依模型声明。
solver/backend 的平衡正确性、边界满足、刚体模态、残差容差和内部变量更新尚待实现。

数值数组不可写，但通用 metadata 仅顶层不可变，不能作为计算状态或缓存身份。
StateRole 与 DIC metadata 白名单防止常见的意外泄漏，不是权限隔离；
数据加载器和训练 pipeline 仍须做 lineage 审计。
极端坐标尺度测试验证了局部归一化，但巨大平移引起的坐标有效位数丢失无法靠插值恢复。
运行环境只验证了本地 Python/NumPy 组合，CI 的其他版本尚未实际执行。

## RL 的科学门槛

当前没有符合动作语义的离线 dataset，没有经验证的 model environment，也没有已确定 reward。
因此 RL 是研究假设。先证明纯物理与观测反演路径，再建立公平 baseline。
若多步监督或参数同化已达到目标，无需为架构完整性引入 RL。
应报告失败和非唯一结果，不能通过弱化约束或仅选择容易样本获得资格。
